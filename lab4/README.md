\# Лабораторная работа №4: Функциональная декомпозиция и критические секции (Задача 6)



Дисциплина: Аппаратные средства телекоммуникационных систем  

Группа: 4404



\## Описание

Программа считывает из файла координаты 3D-точек $(x, y, z)$ и вычисляет общее среднее значение по формуле $(\\sum x + \\sum y + \\sum z) / 3N$ с использованием функциональной декомпозиции (`#pragma omp parallel sections`), общей глобальной суммы и критических секций (`#pragma omp critical`).
