\# Лабораторная работа №3: Геометрический центр 3D-точек (Задача 5)



Дисциплина: Аппаратные средства телекоммуникационных систем  

Группа: 4404



\## Описание

Программа читает координаты точек $(x, y, z)$ из текстового файла (при отсутствии файла автоматически генерирует тестовый набор из $N$ точек) и вычисляет геометрический центр тремя способами:

1\. Последовательный алгоритм.

2\. Декомпозиция по данным (`#pragma omp parallel for reduction(+:...)`).

3\. Функциональная декомпозиция (`#pragma omp parallel sections` — отдельный поток на каждую координату $X$, $Y$, $Z$).



\## Сборка

\### Для Visual Studio:

1\. Включите поддержку OpenMP в свойствах проекта: \*\*C/C++ -> Language -> OpenMP Support -> Yes (/openmp)\*\*.

2\. Выполните сборку решения (\*\*Build Solution\*\*).
