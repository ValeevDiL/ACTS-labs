Дисциплина: Аппаратные средства телекоммуникационных систем Группа: 4404

## Описание файлов

* `main.c` — параллельное перемножение матриц ($N \times N$) с использованием OpenMP[cite: 25, 26], сравнение времени последовательной и параллельной версий на 2, 4 и 8 потоках[cite: 25].

## Сборка программы (Visual Studio / GCC)

### Для Visual Studio:
1. Включите поддержку OpenMP в свойствах проекта: **C/C++ -> Language -> OpenMP Support -> Yes (/openmp)**.
2. Выполните сборку решения (**Build Solution**).

### Для GCC / MinGW (консоль):
```bash
gcc -O2 -fopenmp main.c -o matrix_mul -lm

Команды для запуска:

# Запуск с передачей размера матрицы N и количества потоков через аргументы
./matrix_mul 1000 2
./matrix_mul 1000 4
./matrix_mul 1000 8
